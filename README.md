# viaSocket Assistant — Launch & Intro Website

Single-page intro and launch website for the **viaSocket Assistant** Chrome extension.

## Overview
This standalone repository hosts the public landing page for introducing and installing the viaSocket Assistant Chrome extension.

- **Target Audience**: Automation builders, developers, and viaSocket users.
- **Key Highlights**:
  - Voice-first flow building with SOCKET mascot
  - Step-by-step AI planner
  - On-device speech recognition (Whisper)
  - Seamless canvas integration & embed support
  - [Chrome Web Store Extension](https://chromewebstore.google.com/detail/viasocket-assistant/ikfeheokinklhegllmjkmjgjnmokfabb)
